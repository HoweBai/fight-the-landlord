## 本片裁决（R124–R131）

> 承接切片 8 的 R101–R123。**执行期如发现与本裁决冲突的事实，停下来汇报，不要自行改契约语义。**

| 编号 | 裁决 | 依据 |
|---|---|---|
| **R124** | `room:{code}:seats`（Hash，field = 座位号）是**座位占用的唯一真源**。`room:{code}` 仍是 String(JSON)，但**只存元数据**（`code`/`mode`/`baseScore`/`maxPlayers`/`status`/`createdAt`）——`players` **不再序列化进 JSON**，`Room.players` 是读时从 Hash 投影出来的。§10.1 里「`room:{code}` 也应是 Hash」那半条**不在本片**（对账表里没有独立编号，见文末「延后项」） | §3.1 / §10.1 |
| **R125** | 原子占座 = 逐座位 `HSETNX room:{code}:seats <seat> <JSON Seat>`，`seat` 从 0 递增到 `maxPlayers-1`。**字段名只有 0/1/2 三个取值 ⇒ `HLEN ≤ maxPlayers` 是结构性成立的**，因此**不需要**（也不允许）「先 `HLEN` 再写」的检查-写序列；座位字段**禁止 `HSET`**（无条件覆盖会顶掉别人已占的座位）。损坏/形状非法的字段在读取时丢弃，不让坏数据把服务打崩 | §10.2 |
| **R126** | 重复入座**幂等**：同一 `userId` 再次 `join` 同一房间 ⇒ ack `code 0` + **原来的座位**，不新增、不报 `12002`。理由：客户端重试与 `room.join`（WS 侧本来就是幂等）语义一致；旧实现会 `push` 两次（一人在房间里占两席） | §6.3 / §10.2 |
| **R127** | `join` 的检查顺序固定为 **房间存在（`12001`）→ 未开局（`12008`）→ 占座（满 ⇒ `12002`）**。旧顺序是「满 → 开局」，对「既满又已开局」返回 `12002`，语义不明确 | §11.2 |
| **R128** | `Room.players: Seat[]`（`Seat` 直接 import 自 `packages/protocol`，**不新建同义类型**）。一切「座位号 = `players` 数组下标」的写法改成读 `Seat.seat`；`findOne` 投影时**按 `seat` 升序**排序 | §3.1 |
| **R129** | 匹配路径的座位归属改为读 `RoomsService` 返回的 `Room.players`（`createGameRoom` + 逐次 `addBot` 的返回值链），**删掉 `[...humans, ...bots].map((id, seat) => …)` 这个本地推导** —— 它与 Hash 是两个真源 | R48 / §9.6 |
| **R130** | E10：`startGame` 改走注入的 `HttpService`（`firstValueFrom`），**per-request `timeout: 3000`** 保留 §4.3 的 3s 上限；`match.service.test.ts` 在 `beforeEach` 装「全局 `fetch` 抛错」探针，判据是 **`fetch` 零调用 + `/api/games` 恰好一次**（旧实现 `httpService.post` 从不为 `/api/games` 调用 ⇒ 用例 RED） | 对账表 E10 |
| **R131** | conformance 的判别力来自**直连 room-service（3002）** 的并发，**不是**经网关的并发。实测（本机 2026-09-15，master `852b723` 镜像）：**经网关 20 路并发 3 轮 → 全部 `ok=3 / playerCount=3`**（网关验签 + 白名单查询把到达时刻错峰了，竞态打不出来）；**直连 20 路并发 → `ok=20 / playerCount=1`**。故用例第 ③ 组直连。⚠️ **该「直连即红」的前提当时没写出来，见 R132** | 实测 |
| **R132** | （**执行期裁决**，由 conformance 方在负对照中查出、协调者复核后落盘）**并发窗口的前提是「连接已预热」**：旧实现的丢更新窗口只在「N 条连接已就绪、N 个请求在同一 tick 内被写出」时才打得开。用全局 `fetch` 发 **冷连接** 20 路时，TCP 建连 + accept 把到达时刻**串行化**，localhost 的 `GET→SET`（亚毫秒）往往在下一个请求的数据事件之前就结束 ⇒ 旧实现**意外地正确**（实测 `ok=3 / playerCount=3`，用例会**假绿**）。**处置**：第 ③⑥ 组的并发 burst 改走**显式 keep-alive 连接池**（`node:http` 的 `Agent({ keepAlive: true })`，先 `/api/health` 预热 `BURST + 4` 条），**且预热与 burst 必须用同一个 agent**。**负对照判据以第 ① 组（幂等）为准**（不依赖时序）；第 ③ 组修复后是结构性的（`HSETNX` ⇒ 预热与否都恰好 3 席，**不会假红**）。另一条独立结论：**「不丢人」与「不超员」是两个不变量** —— `playerCount` 只能证不超员（实测旧实现 `ok=4 / playerCount=3`：4 人被告知成功、房间只有 3 席），**`并发成功路数 === 3` 才是「不丢人」的唯一判据** | 实测（conformance 方 4 次重跑 + 协调者独立复核） |
| **R133** | （**执行期裁决**，后端 agent 汇报 + 协调者评审）三件事：① 计划 Step 6 的 `toMeta()` **是死代码**（`noUnusedLocals` 实测 `TS6133`，且计划自己的 Self-Review 与它矛盾）⇒ **删除**，投影约束改由 `writeMeta` **内部**显式构造承担；② **N8 属于本片**（`deviation-ledger.md:142` 逐字指派给「独立小片 7.1（`padEnd(6,'0')` 兜底）」，是**本计划漏抄**）⇒ `generateCode()` 加 `padEnd(6, '0')` + 用例；③ Task 3 里 `timeout: 3000` 保持**字面量**断言（§4.3 的 3s 是契约值，常量被改就该红） | 评审 + 对账表 §1 |

## 执行期裁决落地的代码（R133：Task 1 / Task 3 的修正）

**本节的代码取代正文 Task 1 Step 6 的 `toMeta` + `writeMeta`、取代 Task 1 Step 3 的用例清单的相应部分。**

**① 删掉 `toMeta`（死代码，`TS6133`），投影约束放进 `writeMeta` 内部。**
⚠️ 关键陷阱：`meta: RoomMeta` 只是**编译期**参数类型，运行时被擦除；`updateStatus` 传进来的是含
`players` 的 `Room`，`JSON.stringify(meta)` 会把 `players` 一起落盘 ⇒ 座位出现第二个（会漂移的）真源。
**必须在写函数内部显式构造**，不能指望调用方自觉：

```ts
  /**
   * 元数据写回。
   *
   * ⚠️ **绝不**把 `players` 写回 JSON（R124）：座位的真源是 `room:{code}:seats`。
   * 注意 `meta: RoomMeta` 只是**编译期**类型 —— `JSON.stringify` 会把运行时对象上的
   * **全部**自有属性写出去，所以这里必须**显式**构造要落盘的字段。
   */
  private async writeMeta(source: RoomMeta): Promise<void> {
    const meta: RoomMeta = {
      code: source.code,
      mode: source.mode,
      baseScore: source.baseScore,
      maxPlayers: source.maxPlayers,
      status: source.status,
      createdAt: source.createdAt,
    };
    await this.redis.set(`room:${meta.code}`, JSON.stringify(meta), 'EX', ROOM_TTL_SECONDS);
  }
```

**② N8（计划漏抄的对账表条目）：`generateCode()` 必须 `padEnd(6, '0')`。**

```ts
  /**
   * §3.1：6 位大写 base36 房间号。
   *
   * ⚠️ **必须 `padEnd(6, '0')`**（对账表 N8）：`Math.random()` 的 base36 表示可能很短
   * （恰为 `0` 时是 `"0"`，`0.5` 时是 `"0.i"`），`substring(2, 8)` 于是返回**空串/1~5 字符**，
   * 而网关对路径参数有形状闸 `/^[0-9A-Z]{6}$/`（P0/R72）⇒ 这样的房间号**永远进不去**（判 `10001`）。
   */
  private generateCode(): string {
    return Math.random().toString(36).substring(2, 8).toUpperCase().padEnd(6, '0');
  }
```

```ts
// packages/room-service/src/rooms/rooms.seats.ts
import type Redis from 'ioredis';
import type { Seat } from '@fight-the-landlord/protocol';

/**
 * §10.1：房间座位 Hash。`field = seat`（'0'|'1'|'2'）→ value = JSON `Seat`。
 *
 * ℹ️ 字段名是**座位号**而不是 `userId`（R125）—— 只有 `maxPlayers` 个可能取值，
 * 因此 `HLEN` 天然 ≤ `maxPlayers`，「检查人数 + 占座」不需要是两次操作。
 */
export function seatsKey(code: string): string {
  return `room:${code}:seats`;
}

/** §10.1：房间相关键的 TTL（与 `room:{code}` 的 3600s 一致）。 */
export const ROOM_TTL_SECONDS = 3600;

/** 形状校验：非法 JSON / 缺字段一律当作**没有这个座位**，绝不让坏数据把服务打崩。 */
function parseSeat(raw: string | null): Seat | null {
  if (raw === null) return null;
  try {
    const value = JSON.parse(raw) as Partial<Seat>;
    if (typeof value.userId !== 'string' || typeof value.seat !== 'number' || typeof value.isRobot !== 'boolean') {
      return null;
    }
    return { userId: value.userId, seat: value.seat, isRobot: value.isRobot };
  } catch {
    return null;
  }
}

/**
 * §10.2：**原子**占座（C11 的修复点）。
 *
 * 顺序尝试 `HSETNX` 座位 0…maxPlayers-1：`HSETNX` 是 Redis 单命令原子操作，
 * **不存在**「读到空位 → 别人也读到 → 两人都写」的窗口 —— 这正是旧实现
 * `GET → push → SET` 的缺陷（并发 20 路实测：20 人全部"成功"，房间里只剩 1 人）。
 *
 * 幂等（R126）：`HSETNX` 失败后回读该座位，若已属于同一个 `userId` 就返回它。
 * 这一读**不是**读改写：它不参与写入决定，只用于「我是不是已经坐下了」。
 *
 * ⚠️ 座位字段**不得**用 `HSET` 写（无条件覆盖 ⇒ 会顶掉别人已占的座位）。
 */
export async function claimSeat(
  redis: Redis,
  code: string,
  userId: string,
  isRobot: boolean,
  maxPlayers: number,
): Promise<Seat | null> {
  const key = seatsKey(code);
  for (let seat = 0; seat < maxPlayers; seat += 1) {
    const claimed = await redis.hsetnx(key, String(seat), JSON.stringify({ userId, seat, isRobot }));
    if (claimed === 1) {
      await redis.expire(key, ROOM_TTL_SECONDS);
      return { userId, seat, isRobot };
    }
    const occupant = parseSeat(await redis.hget(key, String(seat)));
    if (occupant?.userId === userId) return occupant;
  }
  return null;
}

/** 读回座位（**按 `seat` 升序** —— Hash 字段顺序不是契约，R128）。 */
export async function readSeats(redis: Redis, code: string): Promise<Seat[]> {
  const raw = await redis.hgetall(seatsKey(code));
  return Object.values(raw ?? {})
    .map(parseSeat)
    .filter((value): value is Seat => value !== null)
    .sort((a, b) => a.seat - b.seat);
}
```

```ts
// packages/room-service/src/rooms/rooms.service.ts
import { Injectable, Logger } from '@nestjs/common';
import Redis from 'ioredis';
import { ErrCode, type Seat } from '@fight-the-landlord/protocol';
import { DomainError } from '../http/errors';
import { claimSeat, readSeats, ROOM_TTL_SECONDS } from './rooms.seats';

export type RoomStatus = 'waiting' | 'playing' | 'finished' | 'cancelled';
export type RoomMode = 'random' | 'practice';

/** `room:{code}` 里**持久化**的元数据（R124：座位不在其中）。 */
export interface RoomMeta {
  code: string;
  mode: RoomMode;
  baseScore: number;
  maxPlayers: number;
  status: RoomStatus;
  createdAt: number;
}

/** §3.1 的服务端内部形状：元数据 + **从 seats Hash 投影出来**的 `players`。 */
export interface Room extends RoomMeta {
  players: Seat[];
}

/** §3.1：`GET /api/rooms` 的列表项。**唯一**的对外房间形状。 */
export interface RoomInfo {
  code: string;
  mode: RoomMode;
  status: RoomStatus;
  playerCount: number;
  maxPlayers: number;
  baseScore: number;
}

export const DEFAULT_BASE_SCORE = 100;

/** 内部 Room → 对外 RoomInfo（§6.4 的同类裁剪思路：只出该出的字段）。 */
export function toRoomInfo(room: Room): RoomInfo {
  return {
    code: room.code,
    mode: room.mode,
    status: room.status,
    playerCount: room.players.length,
    maxPlayers: room.maxPlayers,
    baseScore: room.baseScore,
  };
}

/**
 * 只序列化元数据。
 *
 * ⚠️ **绝不**把 `players` 写回 JSON（R124）：座位的真源是 `room:{code}:seats`，
 * 两处都存就必然出现「JSON 说 3 人、Hash 说 2 人」的漂移，而并发场景下漂移是**必现**的。
 */
function toMeta(room: Room): RoomMeta {
  return {
    code: room.code,
    mode: room.mode,
    baseScore: room.baseScore,
    maxPlayers: room.maxPlayers,
    status: room.status,
    createdAt: room.createdAt,
  };
}

@Injectable()
export class RoomsService {
  private readonly logger = new Logger(RoomsService.name);
  private readonly redis: Redis;

  constructor(redis: Redis) {
    this.redis = redis;
    this.logger.log('Connected to Redis');
  }

  /**
   * §7.3 偏差 A8：**禁止 `KEYS`**（它会阻塞 Redis 单线程），改用游标式 `SCAN`。
   * 同时排除 `room:{code}:cardcount` / `room:{code}:seats` 这类派生键。
   */
  async findAll(): Promise<Room[]> {
    const rooms: Room[] = [];
    let cursor = '0';
    do {
      const [next, keys] = await this.redis.scan(cursor, 'MATCH', 'room:*', 'COUNT', 100);
      cursor = next;
      for (const key of keys) {
        if (key.slice('room:'.length).includes(':')) continue; // 派生键不是房间
        const data = await this.redis.get(key);
        if (!data) continue;
        const meta = JSON.parse(data) as RoomMeta;
        if (meta.status === 'cancelled') continue; // 终态房间不进列表
        rooms.push({ ...meta, players: await readSeats(this.redis, meta.code) });
      }
    } while (cursor !== '0');
    return rooms;
  }

  async create(dto: { mode: RoomMode; roomCode?: string }): Promise<Room> {
    const code = dto.roomCode ?? this.generateCode();
    const meta: RoomMeta = {
      code,
      mode: dto.mode,
      baseScore: DEFAULT_BASE_SCORE,
      maxPlayers: 3,
      status: 'waiting',
      createdAt: Date.now(),
    };
    await this.writeMeta(meta);
    this.logger.log(`Room ${code} created`);
    return { ...meta, players: [] };
  }

  /**
   * §10.2 / C11：入座**必须原子**（`HSETNX`），**禁止 `GET` → 改 → `SET`**。
   *
   * 检查顺序固定（R127）：房间存在（`12001`）→ 未开局（`12008`）→ 占座（满 ⇒ `12002`）。
   * 同一 `userId` 重复入座是幂等的（R126，`claimSeat` 内部处理），返回原座位。
   */
  async join(code: string, userId: string): Promise<Room> {
    const room = await this.findOne(code);
    if (!room) throw new DomainError(ErrCode.ROOM_NOT_FOUND, '房间不存在');
    if (room.status !== 'waiting') throw new DomainError(ErrCode.ROOM_ALREADY_STARTED, '游戏已开始');

    const claimed = await claimSeat(this.redis, code, userId, false, room.maxPlayers);
    if (!claimed) throw new DomainError(ErrCode.ROOM_FULL, '房间已满');

    this.logger.log(`User ${userId} joined room ${code} at seat ${claimed.seat}`);
    return { ...room, players: await readSeats(this.redis, code) };
  }

  async findOne(code: string): Promise<Room | null> {
    const data = await this.redis.get(`room:${code}`);
    if (!data) return null;
    const meta = JSON.parse(data) as RoomMeta;
    return { ...meta, players: await readSeats(this.redis, code) };
  }

  async updateStatus(code: string, status: RoomStatus): Promise<Room> {
    const room = await this.findOne(code);
    if (!room) throw new DomainError(ErrCode.ROOM_NOT_FOUND, '房间不存在');
    const next: Room = { ...room, status };
    await this.writeMeta(next);
    return next;
  }

  /** §9.6 第 3 条：机器人也走**同一个**原子占座入口（`isRobot: true`，`userId` 暂为真实 `bot-*` id）。 */
  async addBot(roomCode: string, botId: string): Promise<Room> {
    const room = await this.findOne(roomCode);
    if (!room) throw new DomainError(ErrCode.ROOM_NOT_FOUND, '房间不存在');

    const claimed = await claimSeat(this.redis, roomCode, botId, true, room.maxPlayers);
    if (!claimed) throw new DomainError(ErrCode.ROOM_FULL, '房间已满');

    return { ...room, players: await readSeats(this.redis, roomCode) };
  }

  /** 元数据写回（**不含** `players`，见 `toMeta`）。 */
  private async writeMeta(meta: RoomMeta): Promise<void> {
    await this.redis.set(`room:${meta.code}`, JSON.stringify(meta), 'EX', ROOM_TTL_SECONDS);
  }
  private generateCode(): string {
    return Math.random().toString(36).substring(2, 8).toUpperCase();
  }

  /** 匹配成功后建局：人类按传入顺序原子坐 0…n-1（§8.2）。 */
  async createGameRoom(playerIds: string[], mode: RoomMode): Promise<Room> {
    const room = await this.create({ mode });
    for (const playerId of playerIds) {
      const claimed = await claimSeat(this.redis, room.code, playerId, false, room.maxPlayers);
      if (!claimed) throw new DomainError(ErrCode.ROOM_FULL, '房间已满');
    }
    const players = await readSeats(this.redis, room.code);
    this.logger.log(`Game room ${room.code} created with ${players.length} players (mode: ${mode})`);
    return { ...room, players };
  }
}
```

```ts
async function joinDirect(user: HarnessUser, roomCode: string) {
  return directJson<unknown>(ROOM_URL, `/api/rooms/${roomCode}/join`, {
    method: 'POST',
    userId: user.id,
    internalToken: INTERNAL_TOKEN,
    body: {},

async function playerCountOf(token: string, roomCode: string): Promise<number | undefined> {
  const list = await getJson<Array<{ code: string; playerCount: number }>>('/api/rooms', token);
  return list.body?.data?.find((r) => r.code === roomCode)?.playerCount;
}

async function createRoom(token: string): Promise<string> {
  const created = await postJson<{ code: string }>('/api/rooms', { mode: 'random' }, token);
  const code = created.body?.data?.code ?? '';
  if (created.body?.code !== ErrCode.OK || code.length === 0) {
    throw new Error(`建房失败：HTTP ${created.status} ${JSON.stringify(created.body)}`);
  }
  return code;
}

  checks.eq((await joinDirect(users[1]!, roomA)).body?.code, ErrCode.OK, 'u1 join code');
  checks.eq((await joinDirect(users[2]!, roomA)).body?.code, ErrCode.OK, 'u2 join code');
  checks.eq(await playerCountOf(owner.accessToken, roomA), 3, '坐满后 playerCount');
  checks.eq((await joinDirect(users[3]!, roomA)).body?.code, ErrCode.ROOM_FULL, '第 4 人 code（12002）');
  checks.eq(await playerCountOf(owner.accessToken, roomA), 3, '被拒后 playerCount 不变');

  // ── ③ 并发占座（§10.2 的核心：不丢人） ─────────────────────────
  step(`③ ${BURST} 路**直连并发** join 同一空房 → 恰好 3 个 code 0、其余 12002、playerCount = 3`);
  const roomB = await createRoom(owner.accessToken);
  const results = await Promise.all(users.map((u) => joinDirect(u, roomB).then((r) => r.body?.code)));
  const winners = users.filter((_, i) => results[i] === ErrCode.OK);
  checks.eq(winners.length, 3, `并发成功路数（旧实现实测 ${BURST} 路全部成功）`);
  checks.eq(results.filter((c) => c === ErrCode.ROOM_FULL).length, BURST - 3, '被 12002 拒绝的路数');
  checks.eq(
    results.filter((c) => c !== ErrCode.OK && c !== ErrCode.ROOM_FULL).length, 0,
    '没有第三种错误码（尤其不能是 10002：内部 token 没带对）',
  );
  checks.eq(await playerCountOf(owner.accessToken, roomB), 3, '并发后 playerCount（旧实现实测 = 1）');
  await sleep(300);
  checks.eq(await playerCountOf(owner.accessToken, roomB), 3, '静默窗后 playerCount 仍是 3（无迟到写入）');

  // ── ④ 反例：并发落败者**真的**没座位（否则「3 个赢家」可能是假象） ──
  step('④ 并发落败者 room.join（WS）→ 12004（不是成员，确实没入座）');
  const loserIndex = results.findIndex((c) => c === ErrCode.ROOM_FULL);
  checks.that(loserIndex >= 0, `存在落败者（index=${loserIndex}）`);
  const loserClient = await HarnessClient.connect('loser', users[loserIndex]!);
  try {
    checks.eq((await loserClient.send('room.join', { roomCode: roomB })).code, ErrCode.NOT_IN_ROOM, '落败者 room.join code');
  } finally {
    loserClient.close();
  }

  // ── ⑤ 同一真源：HTTP 占座的赢家 = WS 视图里的成员，座位恰好 {0,1,2} ──
  step('⑤ 并发赢家 room.join（WS）→ 成员恰好 3 席、座位 {0,1,2}、自己真的在里面');
  const winnerClient = await HarnessClient.connect('winner', winners[0]!);
  try {
    const ack = await winnerClient.send('room.join', { roomCode: roomB });
    checks.eq(ack.code, ErrCode.OK, '并发赢家 room.join code');
    const players = (ack.data?.players ?? []) as Array<{ id: string; seat: number }>;
    checks.eq(players.length, 3, 'WS 视图里的成员数');
    checks.eq(
      players.map((p) => p.seat).sort((a, b) => a - b).join(','), '0,1,2',
      '座位集合恰好 {0,1,2}',
    );
    checks.that(
      players.some((p) => p.id === winners[0]!.id),
      'HTTP 占座的赢家出现在 WS 成员表里（seats Hash 是同一真源）',
    );
    checks.that(!JSON.stringify(ack.data ?? {}).includes('isRobot'), 'ack 不泄漏 isRobot（§6.4 规则 3）');
  } finally {
    winnerClient.close();
  }

  // ── ⑥ 已坐满 + 并发 → 不超员（正向对照；旧实现也过，防「修成一律放行」） ──
  step('⑥ 先坐满 3 人，再并发 17 路 → 全部 12002、playerCount 恒为 3');
  const roomC = await createRoom(owner.accessToken);
  for (const u of users.slice(0, 3)) {
    checks.eq((await joinDirect(u, roomC)).body?.code, ErrCode.OK, `${u.nickname} 占座 code`);
  }
  const late = await Promise.all(users.slice(3).map((u) => joinDirect(u, roomC).then((r) => r.body?.code)));
  checks.eq(late.filter((c) => c === ErrCode.ROOM_FULL).length, late.length, '迟到者全部 12002');
  checks.eq(await playerCountOf(owner.accessToken, roomC), 3, '并发拥挤后 playerCount（不超员）');

  info(`房间：A=${roomA}（幂等/满座）· B=${roomB}（${BURST} 路并发）· C=${roomC}（不超员对照）`);
  return checks;
}
```
