### R500 —— 处置方式裁决：§11 表的 `[偏差]` 行**删除**，而 `[待实现]`/`[部分实现]` 行**flip**

§11 是「实现现状对照」**状态表**，行既是「规则」也是「状态标记」。两种做法都能自洽，本片的选择与理由：

- **`[偏差]` 行 → 删除**（17 行）：① R493 的四种处置里「删除」正对应「代码证伪了它」；
  ② **两个只读审计 agent 独立地都判「删除」**（Part A 9/9、Part B 22/23）；
  ③ P8 的先例是「**行内** `[偏差]` 注记 → 删除」（`doudizhu.md` 的 C16/C17、`design.md` 的 14 处），
  而这些行在结构上是**行内注记**（每行 = 规则 + 偏差描述），不是 `design.md` 的大纲级标记（那批是「上调 `[已实现]`」）。
- **`[待实现]`/`[部分实现]` 行 → flip `[已实现]`**（3 行）：它们**不是偏差记录**，而是**状态条目**
