# ②金币场（P2-②）实施计划 v1.0

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 把货币接到对局上并把金币场玩家可见面全部落地——金币场（新 mode）+ 双开关 + 门槛 + 对局结算 + 机器人虚拟币池 + 救助 + 观测（`slice-18` 收口）。

**架构：** 结算/资金算式**住在 room-service**（`finalizeRoomEnd` 独立例程 + Redis outbox + 10s sweeper，失败不卡对局）；`currency-service` 保持纯账本（apply/get 零改动 + 上限 source 化 + 救助端点 + 首接配置）；协议三值化 `'gold'` + 新 S→C `game.balances` + 新 RPC `record.moneyDelta`；配置 11→17 键、客户端配置 3→7 键、错误码 +3、告警 13→16 条。

**技术栈：** NestJS 11 · TypeORM 0.3 + mysql2 · ioredis · prom-client（shared 构造器）· vitest · pnpm + turbo · Node 20 · uni-app（客户端）。
