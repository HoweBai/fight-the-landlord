### 1.5 连不上时按这个顺序查

| 症状 | 先查 |
|---|---|
| 手机浏览器开 `http://192.168.5.27:3000/` **一直转圈 / 拒绝连接** | ① 是否同一 wifi ② Windows 防火墙是否挡了入站 3000（docker 首次发布端口时通常弹过窗） |
| 手机浏览器**能开**（哪怕是 404 页）但 App 里注册转圈 | 疑似 HTTP 明文被拦 —— Android 9+ 默认禁 cleartext。**把现象原文记下来**，我们再决定加 `usesCleartextTraffic` 还是别的办法 |
| HBuilderX 一运行就**白屏、控制台无红字** | 十有八九是 HBuilderX 版本 < 编译器版本 ⇒ 升级 HBuilderX |
| 控制台**有红字** | **整段复制**（含堆栈）—— 这本身就是有价值的结论 |

> 「能看到任何 HTTP 响应」= 网络通（连 404 都算响应）⇒ 这一条把「网络不通」和「App 自身问题」干净地分开。

### 🔴 为什么「安全区」只能记「未验」

模拟器若**未配 display cutout**，`getSystemInfoSync().safeArea` 返回整屏 ⇒ insets **0** ⇒
「没被刘海吃掉」是**必然的**，不构成证据。本次能证的只有**降级路径**：
[useLandscapeCanvas.ts:70-71](apps/client/src/composables/useLandscapeCanvas.ts#L70-L71)
那条自己标了「未验事项」的回落分支（取不到 ⇒ 回落 0 ⇒ 行为等同无安全区）**确实不炸**。
⇒ 那条「uni-app 在 App 端到底返不返回有意义的 `safeArea`、返回值语义对不对（坐标 vs inset）」
**仍然未验**。要关掉它需要**带 display cutout 的 AVD 或物理机**（本次用户明确不关注 ⇒ 保留为未验项）。
