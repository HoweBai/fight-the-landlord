# 货币核心（P2-①）实施计划 v1.1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 落地 `currency-service`（钱包/账本/幂等/管理发放/对账自检），暗上线——玩家可见面为零。

**架构：** 新 Nest 服务（HTTP 3004 / RPC 3104 / metrics 9004）+ TypeORM/MySQL 三表（共享库 `fight_the_landlord`，迁移表 `migrations_currency`）+ Redis 只读缓存；**写路径唯一入口** RPC `currency.apply`（actionId 幂等）；user-service 注册链路接入（先货币后落库）；网关新增 4 条路由；reconcile 自调度循环（账实相符/缓存自愈/孤儿诊断）。

**技术栈：** NestJS 11 · TypeORM 0.3 + mysql2 · ioredis · prom-client（shared 构造器）· vitest · pnpm + turbo · Node 20（node:20-alpine）。

## Global Constraints（每条任务隐含，逐字遵守）

- **端口写死**：HTTP **3004** / RPC **3104** / metrics **9004**（全仓其余地方不得占用）。
- 容器 `ftl-currency-service`；镜像 `${IMAGE_PREFIX:-pokergame}-currency-service:${IMAGE_TAG:-latest}`；compose 块照 `docker-compose.yml:132-199`（user-service）形态：logging 上限、`expose`（不发布宿主）、healthcheck、`networks: [ftl-platform]`。
- **不新增 npm 依赖**；Nest 11 / TypeORM 0.3 + mysql2 / ioredis / prom-client（经 `packages/shared/src/metrics/` 构造器）。
- `INTERNAL_SERVICE_TOKEN` **fail-closed**（未配 ⇒ `process.exit(1)`）；metrics 端口 Bearer 守卫；健康豁免面精确 `['/api/health','/api/health/live']`。
- 金额列 `int`、时间列 `datetime(3)`、wire 一律 epoch ms、id `bigint AUTO_INCREMENT`（读出转 number）。
- **DI 纪律**：要注入的类型必须**值导入**（`import type` 让容器启动即崩，单测与 tsc 都看不见）。
- **模块注册纪律（T6 教训）**：控制器/接收器/自调度服务未在某 `*.module.ts` 注册 = 单测全绿而**真容器 404/永不执行**。
- **凡改了会被某闸扫描的文件，改完必须跑那条闸**（监控片 B1 前科）；「恰好 N」断言改数字必须同提交改断言本体。
- 每次改动**一个提交**（消息结尾 `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`）。
- 迭代期**只跑受影响包的测试**；六阶段（`pnpm run ci`）只在 push 前跑一次；全序 conformance 只在验收跑一次。
- slice-17 **零 `skip()`、零分支**（基线静态回填的前提）；判定对象 = 真后端回答。

**开工必读（每任务开始时先读）：** `docs/superpowers/specs/2026-10-03-currency-design.md`（v1.1.1）+ `docs/superpowers/specs/2026-10-03-currency-spec.md`（v1.0，含 ⚙️1–⚙️11）；任务卡内的「规格映射」列到行级，实施只按映射与契约写，**不得另行发挥**。
