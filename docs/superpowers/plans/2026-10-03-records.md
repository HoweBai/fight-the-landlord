# 记录片实施计划（v2 —— 过计划审查后订正 3🟠+3🟡，内容即 v2）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每局结束把「结算 + 发牌快照」落进 MySQL（一处写、幂等、事务）；玩家从大厅头像点进「历史战绩」看自己的对局；保留期 = 配置中心第 10 键（默认 365 天）+ 自建清理。

**Architecture:** game-service 在发牌点给 `GameSession` 记 `initialHands` 冻结副本 → `publishEnded` 附 `record` 信封（内部通道、客户端零变化）→ room-service（座位→userId / mode / `room:{code}:bots` 座位对齐）组装 → **新 RPC `record.write`**（user-service 重挂 TCP 3101）→ user-service 事务落两表；读取 = `GET /api/records/mine`（JWT 本人、keyset、白名单 DTO）；保留期 = config 键 + user-service 首条配置消费链 + 自调度清理。

**Tech Stack:** NestJS（protocol/shared/game/room/user/config）· TypeORM/MySQL · Redis pub/sub · Nest TCP RPC · uni-app（client）· vitest · conformance（真栈切片）· docker compose。

**权威文本（遇到与真实代码冲突 ⇒ 停下报协调者，不自行改设计）：** 规格 **v1.1 定稿** `docs/superpowers/specs/2026-10-03-records-spec.md` · 设计 **v1.2 定稿** `…-design.md` · 审查史 `.superpowers/sdd/2026-10-03-records/`。
